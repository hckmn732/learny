(commit de validation consigné dans `summary.md`).

- ✅ **CA-1** — `api/openapi.yaml` est un document OpenAPI 3.1 valide (validé par `@readme/openapi-parser`), décrit **217 opérations** (chacune avec son bloc `x-learny`) et **398 schémas nommés** ; `api/errors.json` liste **104 codes d'erreur** et `api/events.schema.json` les **49 événements** d'outbox. Preuve : `packages/contracts/scripts/export-contract.ts`, `api/openapi.yaml`, `api/errors.json`, `api/events.schema.json`, tests `[SPEC-2002]` « is a valid OpenAPI 3.1 document (CA-1) » et « describes the 217 operations with the x-learny policy and named schemas (CA-1) ».

- ✅ **CA-2** — Le SDK TypeScript est généré depuis le contrat dans `packages/api-sdk/src/schema.d.ts` (754 Ko, 217 opérations `operations["…"]`), commité et contrôlé à jour par `pnpm sdk:check` (lui aussi branché sur `lint`). Le web compile et l'ensemble de la suite unitaire passe sans aucune assertion modifiée ; le test `[SPEC-2002]` « exposes every operation id of the inventory (CA-2) » vérifie que chaque identifiant de l'inventaire figure dans les types générés, et un test de types (`expectTypeOf`) verrouille les opérations de lecture. Preuve : `tools/contract/generate-sdk.mjs`, `packages/api-sdk/src/schema.d.ts`, `packages/api-sdk/src/schema.test.ts`.

- ✅ **CA-3** — `tools/contract/compat.mjs` détecte une rupture injectée (opération retirée, schéma de réponse modifié, paramètre supprimé, sécurité changée, statut d'erreur retiré) et accepte une exception **uniquement** si `api/contract-exceptions.yaml` la rattache à un ADR `ADR-xxxx` (CL-3) ; une exception sans ADR est refusée. Comparé aux documents réels, l'outil ne signale **aucune rupture** entre `api/openapi.yaml` et `apps/api/openapi.json` (CL-2). Preuve : `tools/contract/compat.mjs`, `api/contract-exceptions.yaml`, tests `[SPEC-2002]` « detects a removed operation and a changed response schema (CA-3) », « accepts a breaking difference listed with an ADR and rejects one without (CL-3) », « reports no semantic difference between the source YAML and the served JSON (CL-2) », et le test d'intégration `tools/contract/test/integration/contract.test.ts`.
