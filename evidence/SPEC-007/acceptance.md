# SPEC-007 — critères d'acceptation

- ✅ CA-1 — preuve : `integration.json` (« [SPEC-007] web /api/inngest » : le registre partagé est servi par l'adaptateur Next.js ; « [SPEC-007] worker » : `GET /health` limité à `status`/`version`/`commit`, même registre servi à `/api/inngest`, aucune clé exposée ; « worker exécute le job partagé via Hono »). `unit.json`/`integration.json` (« Inngest function exposes one shared registry built on the learny client with three retries ») attestent un registre unique importé par les deux hôtes.
- ✅ CA-2 — preuve : `unit.json` (« demo job runs validate-input then persist-result and returns the doubled value », « writes once for a duplicated runId and returns the same result ») et `integration.json` (« runs both steps through the SDK protocol and returns the doubled value », « writes once when the same runId is delivered twice ») avec compteur d'écritures ; `e2e.json`, test « exécute un job SDD @SPEC-007 » : valeur 4 → étapes « Terminée » → résultat 8.
- ✅ CA-3 — preuve : `unit.json` (« retries only the failing step after a transient error », « stops after three retries at most », « never retries a permanent error and logs it safely ») et `integration.json` (« replays only the failed step after a transient error », « stops after three retries at most ») : `validate-input` n'est pas rejouée, trois reprises au plus, erreur permanente non reprise et journalisée sans valeur d'entrée.
- ✅ CA-4 — preuve : `integration.json` (« [SPEC-007] web /api/inngest refuses an unsigned execution request outside dev mode, before the job », « worker refuses a missing or invalid signature in production before the job », contrôle positif « accepts a correctly signed request in production ») : la requête est refusée avant toute exécution ; la clé de signature reste côté serveur.
- ✅ CA-5 — preuve : `e2e.json` et `video/` : tests « exécute un job SDD @SPEC-007 » (états « En attente »/« En cours »/« Terminée », résultat réel, `aria-live`) et « signale les échecs sans détail technique » ; test `@visual` « démonstration des jobs conforme @SPEC-007 » : ordre des quatre régions, jetons, axe sans violation serious/critical, captures desktop 1440×900 et mobile 390×844 à 1 % (`screenshots/`, `visual/`). `checks.json` atteste lint, typecheck, build, unit, intégration, e2e et visuel.
