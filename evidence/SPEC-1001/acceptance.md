# SPEC-1001 — critères d'acceptation

- ✅ **CA-1** — Une poussée sur `migration` déclenche la CI ; `deploy.yml` ne contient aucun chemin de déploiement exécutable pour `migration` ni pour `spec/SPEC-1*` (vérifié par test du workflow). Preuve : bloc `[SPEC-1001]` de `tools/ci/check-workflows.test.ts` — 4 tests verts (rapport `unit.json`) ; commit `383edbd1` : `ci.yml` déclencheur push `migration`, `deploy.yml` preview exclut `migration` et `!startsWith(..., 'spec/SPEC-1')`, production inchangée derrière un tag `v*` appartenant à `main` (`git merge-base --is-ancestor`).
- ✅ **CA-2** — Ajouter un import `@learny/services` dans un nouveau fichier de `apps/web` fait échouer le lint ; la liste de référence initiale fait passer le lint sur l'existant. Preuve : `tools/migration/test/integration/boundary-lint.test.ts` — refus avec le message ADR-1003 et passage d'un fichier de la liste (rapport `integration.json`, journal `lint-refus-ca2.txt`) ; `pnpm exec eslint --max-warnings=0 apps/web` vert sur l'arbre complet avec la règle active ; liste de référence : 80 fichiers + glob `apps/web/app/api/**` (`web-boundary-baseline.json`).
- ✅ **CA-3** — Une entrée périmée dans la liste de référence fait échouer le test de frontière. Preuve : `tools/migration/test/unit/boundary.test.ts` — « échoue sur une entrée qui n'importe plus de paquet serveur » et « échoue sur une entrée dont le fichier a disparu » (rapport `unit.json`, 5 tests verts).
- ✅ **CA-4** — `sync-main.mjs` résout automatiquement un conflit limité au suivi et s'arrête (code 2, sans commit) sur un conflit de code. Preuve : `tools/sdd/test/integration/sync-main.test.ts` — 6 tests verts : conflit de suivi seul → commit `merge(sdd): synchronise main dans migration` ; conflit de code (seul et combiné CL-4) → code 2 sans commit, fusion laissée en cours ; branche `main` absente → sortie 1 (rapport `integration.json`, journal `sync-main-ca4.txt`).
- ✅ **CA-5** — La page de démonstration affiche les nombres réels du rapport et passe les contrôles visuels. Preuve : e2e `affiche le couplage du web @SPEC-1001` — valeurs exactes lues de `progress/migration.json` (pages 8, lib 28, components 15, dev 28, proxy 1, apiRoutes 150, total 80 hors app/api, registre 169, route.ts 154, 6 composants client) et `démonstration de la piste conforme @SPEC-1001 @visual` — jetons du thème, ordre des trois régions, axe sans violation sérieuse, captures desktop 1440×900 et mobile 390×844 avec `maxDiffPixelRatio: 0.01` (rapport `e2e.json`, `video/`, `visual/`).

Note de mesure : §2 de la spécification annonce « 79 fichiers » alors que ses propres catégories somment à 80 (8+28+15+28+1) — le rapport mesure l'état réel du dépôt (80 au démarrage de la piste, inchangé par les fusions de `main` depuis) ; la page affiche les nombres réels, conformément à CA-5.
