# ADR-0051 — Versionnement Git

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-002

## Contexte

Préparation du dépôt ; le distant est créé par le porteur.

## Décision

Règles de `docs/engineering/git.md` : `main`, branches `spec/<ID>-<slug>`, Conventional Commits avec la spécification en portée, fusions `--no-ff`, tags `cp-n` et SemVer, aucun dépôt distant créé par un agent.

## Conséquences

Aucune conséquence particulière au-delà de la décision.
