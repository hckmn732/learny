# ADR-0009 — Langues

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-602, SPEC-707

## Contexte

Interface et contenus.

## Décision

Interface en français uniquement (messages centralisés `apps/web/messages/fr.ts`, prêts pour l'internationalisation). Langue des cours par utilisateur : fr, en, es, de (défaut fr) ; le tuteur rédige dans cette langue quelle que soit celle des ressources.

## Conséquences

Les consignes au modèle sont en anglais (ADR-0073).
