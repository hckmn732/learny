# ADR-0010 — Ton du tuteur

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-508, SPEC-209

## Contexte

Vouvoiement ou tutoiement.

## Décision

Défaut `vous` ; `tu` possible dans le profil. Appliqué à tout texte rédigé par le tuteur et aux messages des notifications/automatismes ; les libellés fixes de l'interface restent au vouvoiement.

## Conséquences

Les gabarits de notification ont deux variantes de texte.
