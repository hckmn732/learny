# ADR-0074 — Fonctions V2 désactivées

- **Statut** : Acceptée
- **Origine** : Déduite (décision déduite lors de la préparation du référentiel, sur la base des travaux existants et des standards)
- **Date** : 2026-11-11
- **Liens** : SPEC-901 à SPEC-908

## Contexte

Livrer V1 sans code mort exposé.

## Décision

Les fonctions V2 sont développées en phase P9 seulement ; aucun drapeau de fonctionnalité en V1.

## Conséquences

Aucune conséquence particulière au-delà de la décision.
