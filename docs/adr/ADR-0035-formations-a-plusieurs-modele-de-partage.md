# ADR-0035 — Formations à plusieurs : modèle de partage

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-111, SPEC-724

## Contexte

Programme et agenda communs, données personnelles privées.

## Décision

Les membres partagent la ligne `formations` (programme, notions, liens de programme, jalons) ; toutes les données personnelles sont indexées par utilisateur. 10 membres max. Code `LRN-XXXX` (alphabet sans caractères ambigus). Seul le propriétaire modifie le programme. Un membre qui quitte reçoit une copie individuelle du programme et conserve ses données. Les créneaux de chaque membre sont planifiés dans les fenêtres communes des modules.

## Conséquences

Aucune conséquence particulière au-delà de la décision.
