# ADR-0008 — Types d'apports par version

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-607, SPEC-901

## Contexte

Le porteur du projet a fixé les formats.

## Décision

V1 : note (texte/Markdown), PDF, page web (URL), vidéo YouTube (sous-titres), image/capture. V2 : fichiers audio et vidéo avec transcription. Un « guide d'examen » est un PDF ou une page web marqué `exam_guide`.

## Conséquences

Le type `audio`/`video` existe dans l'énumération dès V1 mais l'interface ne le propose qu'en V2.
