# ADR-0059 — Design system

- **Statut** : Acceptée
- **Origine** : Déduite (décision déduite lors de la préparation du référentiel, sur la base des travaux existants et des standards)
- **Date** : 2026-11-11
- **Liens** : SPEC-301 à SPEC-303

## Contexte

Composants accessibles et fidèles aux maquettes.

## Décision

`packages/ui` : composants maison stylés avec les jetons, primitives Radix UI pour Dialog, Popover, DropdownMenu, Tabs, Switch, Tooltip ; icônes `lucide-react` (style trait proche des maquettes) ; polices Inter et Space Grotesk via `next/font`.

## Conséquences

Aucune conséquence particulière au-delà de la décision.
