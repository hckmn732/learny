# ADR-0055 — Notifications navigateur

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-205

## Contexte

Web d'abord.

## Décision

Web Push standard (VAPID) avec la bibliothèque `web-push` ; abonnements supprimés après une réponse 404/410 ou 5 échecs.

## Conséquences

Aucune conséquence particulière au-delà de la décision.
