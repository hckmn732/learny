# ADR-0005 — Périmètre produit

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : docs/product/vision.md

## Contexte

La cible commerciale et le périmètre ont été tranchés avec le porteur du projet.

## Décision

Cible V1 : particuliers. V1 = toutes les règles de priorité V1 de `docs/product/business-rules.md`, livrées ensemble (pas de version intermédiaire réduite). V2 = phase P9. Hors périmètre : offre entreprise, applications natives, interface multilingue, classements, marketplace.

## Conséquences

Aucune spécification ne doit implémenter un élément hors périmètre.
