# ADR-0015 — Fin de formation et entretien de mémoire

- **Statut** : Acceptée
- **Origine** : Validée (décision prise avec le porteur du projet)
- **Date** : 2026-11-11
- **Liens** : SPEC-617

## Contexte

Choix du porteur : bilan final + choix de l'apprenant.

## Décision

À la validation du dernier module : bilan final. Entretien léger = quiz global plafonné à 5 min/jour sur les notions dues, sans automatismes autres que le rappel quotidien. Arrêt = plus aucune révision ni notification pour cette formation.

## Conséquences

Le choix est modifiable ensuite depuis le bilan.
