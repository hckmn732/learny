# ADR-0041 — Budgets de performance

- **Statut** : Acceptée
- **Origine** : Déduite (décision déduite lors de la préparation du référentiel, sur la base des travaux existants et des standards)
- **Date** : 2026-11-11
- **Liens** : SPEC-804

## Contexte

Qualité perçue.

## Décision

LCP < 2,5 s, INP < 200 ms, CLS < 0,1 (p75, Lighthouse CI sur les écrans principaux en profil mobile), API p95 < 300 ms hors IA (test de charge k6 sur 50 utilisateurs virtuels).

## Conséquences

Aucune conséquence particulière au-delà de la décision.
